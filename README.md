## Where the coupon box actually is

Enter your HP code on the cart page only; there is no second opportunity at checkout. The field is labeled **E-Coupon code** and sits inside the Order Summary section: on the right side of the screen on desktop, near the bottom on mobile. Paste the code, hit Apply, and the total updates before you proceed.

The full sequence, which works the same for guest checkout and logged-in accounts:

1. Add your item on HP.com and confirm the pop-up.
2. Go to the **Shopping Bag** page.
3. Find the **E-Coupon code** field in the Order Summary and paste your code.
4. Click **Apply** and verify the new total before moving on.

If you remember your code mid-checkout, you are out of luck twice over: there is no field at that stage, and HP does not support applying a code retroactively to a completed order.

When a code silently refuses to work, it is almost always one of these:

- **Wrong store version.** Some codes only work in the general HP store; others are built for the Education or Frontline Heroes stores. A code entered in the wrong storefront fails without an explanation.
- **A bundle or gift card in the cart.** Adding either can break many codes. Remove the item and try again.
- **A minimum price range.** Some codes require a price floor, and if the sale price already sits below it, the code will not apply.
- **Category exclusions.** Printers, ink, toner, refurbished units, and many accessories are excluded from most codes.
- **A previously used code.** HP tracks one redemption per customer email and account. A one-time code you used on an old order will not activate again.

## The rules that decide whether your code works

HP's system stacks restrictions on three levels, and knowing them saves you a frustrating checkout.

One code per order, first. There is no combining. If the 20% code and the $135 business code both look relevant to your cart, you have to pick.

One redemption per account, second, tracked by your email. Reusing a personal code on a family member's account does not reset anything; the code itself is capped.

SKU-level eligibility, third. Most codes apply only to specific product listings. This is why a code can work on one configuration of an OMEN and fail on another even when the coupon page promises a broad discount.

There is also a category of purchases where hunting for a code is wasted effort: ink, toner, and paper are excluded from nearly everything, refurbished and Outlet items rarely qualify, and Education Store pricing already discounts deeper than most public codes. Skip the search for those carts.
